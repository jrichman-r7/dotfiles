# dotfiles

Personal dotfiles and shell configuration.

## Overview

This repository contains shell-based dotfiles used to configure the command-line environment.

## Contents

- Shell configuration files
- Aliases and functions
- Environment setup scripts

## Usage

Clone the repository and symlink or copy the files you want into your home directory.

```sh
git clone https://github.com/jrichman-r7/dotfiles.git
cd dotfiles
```

Then review the files and install them as needed for your system.

## Notes

Because dotfiles are highly personal, you may want to customize paths, aliases, and environment variables before using them on another machine.
